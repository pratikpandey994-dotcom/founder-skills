# Case 02 — the calibration ceiling

The bioinformatics pipeline case. Deliberately the strongest profile this audience
produces: paying customers, clean IP, full-time founders, runway, a selling co-founder.
Recorded verdict on 2026-09-19 was CONDITIONAL GO at 6.1.

If this ever returns NO-GO, something regressed badly. If it returns GO, the scoring
has loosened and that is a deliberate decision, not a drift — check it was intended.

**Idea:** Bioinformatics postdoc in Bangalore. Pipeline cleans and annotates single-cell
RNA-seq data, cutting analysis from 2 weeks to 1 day. 6 academic labs and 2 biotech
startups use it; 3 pay Rs 25,000/month against Rs 15,000/month total AWS cost. Two more
labs asked for quotes. Going full-time next month, Rs 12 lakh savings, ~18 months runway,
open to grants and investors. Co-founder is an ex-sales manager at a lab-equipment
distributor with contacts at ~200 Indian labs, also full-time. Built on own time with
open-source tools; institute confirmed in writing it has no claim. No patent.
India first, then Southeast Asia. Goal: replace both salaries in 12 months.
